Task 9: RAID levels

Identify the RAID level of each array, then choose the best description. (From your RAID and NAS lessons.)

  1. P
  2. Q
  3. R

Why: RAID 0 splits data across disks for speed but has no redundancy; RAID 1 writes identical copies so one disk can fail; RAID 5 spreads data and parity across three or more disks so any one disk can fail and be rebuilt.
