# Unit 2 scan informed revision companion

The supplied 32-page scan is a guided Pearson revision workbook, with a first supported test and a second less-guided test. It is **not** a set of past live exam papers. This companion extracts its teaching pattern and creates original practice; it does not reproduce its questions or model responses. Some photographed pages are skewed, cropped, duplicated or too faint for dependable OCR. The separate OCR transcript is a search aid only and should be checked against page images.

## How the workbook teaches exam technique
A single workplace scenario can generate a short identification, a calculation, an annotated diagram, an applied explanation and a 6–12 mark discussion/evaluation. Read all subparts before starting; identify which facts belong to the scenario; write the correct number of distinct points for short mark allocations; show calculation working; annotate diagram paths; connect each paragraph of an extended response to a given constraint; conclude when asked to evaluate. The specification, rather than the workbook, sets the authoritative topic and AO ranges.

## A Hardware and software
The scan's business, retail and security scenarios repeatedly connect device selection, interfaces, access control, shared storage and recovery. Revise what a component or process does, then what happens when it fails. A menu-based till can reduce training and restrict available actions, but accessibility and exceptional transactions still matter. A biometric factor can reduce card-sharing, but visitors need a different controlled route. Backup creates recoverable copies; an archive retains records for longer-term reference; RAID preserves availability under certain disk failures but does not replace backup.

**New practice:** A community pharmacy uses shared terminals and a nightly NAS backup. State two reasons to restrict the till interface [2]. Explain why a mirrored NAS needs an independent restore plan [4]. Evaluate whether a card-only entry system meets the pharmacy's needs for employees and visiting contractors [8].

## B Computer architecture
The scan asks learners to fill architecture diagrams, trace PC/MAR/MDR/instruction register roles and discuss parallel processing. For a fetch, separate an address in PC/MAR from instruction data in MDR/IR. A Harvard design has separate instruction and data paths in the conceptual model. A cluster distributes work across computers; multiple cores are within a computer; neither automatically eliminates all memory and communication bottlenecks. Emulation may introduce performance, compatibility and graphics constraints.

**New practice:** A museum wants to run an old interactive exhibit on replacement equipment. Draw an annotated fetch path [4]. Explain two limits of emulating the older application [4]. Discuss when a cluster rather than a more capable single computer would support the museum's ticketing service [8].

## C Data representation
The workbook mixes ASCII and BCD in one data item and asks for parity and image choices. Always partition a bit string according to the stated encoding before decoding. Character codes and BCD digits are different. For raster images, distinguish the full-resolution master from resized delivery versions and identify which detail is lost under lossy compression. Vector drawings store geometric descriptions that scale differently from photographs. Vector image representation may be useful extension context even though the supplied specification's C3 essential content expressly concerns bitmap/raster data.

**New practice:** A visitor badge stores one ASCII capital letter followed by two BCD digits. Decode `01000011 0010 0111` [3]. A 1200×800 raster image uses 24 bits per pixel: calculate raw pixel-data bytes [3]. Explain why an organisation would keep the original master before creating website thumbnails [4].

## D Data organisation
The scan uses ordered media playback and scheduling to prompt queue reasoning, and a sales grid to prompt matrix operations. FIFO fits a service line where earliest eligible item is served first; a stack would reverse that order. Matrix addition requires matching dimensions; matrix multiplication combines row-by-column products and requires compatible inner dimensions. Transpose swaps rows and columns.

**New practice:** A repair desk receives devices P, Q, R in order. Draw the queue after P has been served [2]. Given two workers' weekly totals `[[3,5],[4,2]]` and `[[1,2],[2,3]]`, add the matrices [4]. Explain why a priority repair would require an explicit scheduling rule beyond a simple FIFO queue [4].

## E Data transmission
The scan links handshakes, packet fields, checksums, error handling and public-key/symmetric encryption to practical connections. Packet source/destination identify endpoints, sequence numbers support ordering, and checksums help detect corruption. A handshake coordinates a connection or transfer parameters. Public-key mechanisms can help establish trust or a shared session key; efficient bulk data is then protected with an appropriate symmetric cipher in a properly designed protocol. **Historical warning:** the scan discusses DES as if it were a secure option; do not recommend 56-bit DES for a new system. The scan's example certificate dates and product references are historic.

**New practice:** A remote sensor sends three numbered packets, one of which fails an integrity check. State the role of the sequence number and check value [2]. Explain an ARQ response [3]. Evaluate whether retransmission or FEC is better if a safety dashboard must update quickly over a high-latency link [8].

## F Logic and data flow
The scan links a Boolean expression to its truth table and circuit. Translate `.` to AND and `+` to OR only after confirming the notation; perform AND before OR, unless brackets say otherwise. For `A·B + B·C`, output is 1 for input triples 011, 110 and 111 when listed A,B,C. Draw two AND gates feeding one OR gate, with B feeding both AND gates. Check all eight combinations and label every connection.

**New practice:** Make the eight-row truth table for `(A AND B) OR (A AND C)` [5]. Draw the equivalent circuit [3]. Explain why changing the OR gate to XOR alters the output for A=B=C=1 [2].

## Answer checkpoints for the new practice
- C: `C27`; 1200×800×24÷8 = 2,880,000 bytes of pixel data. Keep the full-resolution source for later cropping, print or improved delivery versions.
- D: after serving P, front Q and rear R; sum `[[4,7],[6,5]]`; priority work needs a documented override or priority queue to avoid arbitrary order.
- F: output 1 for 101, 110 and 111 in A,B,C order. At 111, both AND outputs are 1, so XOR would output 0 rather than OR's 1.

For the longer responses, credit technically accurate consequences tied to the scenario, limitations, and a justified conclusion. Do not use these checkpoints as an official Pearson mark scheme.
